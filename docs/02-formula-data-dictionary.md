# Formula and data dictionary

> Generated by `scripts/build-docs.js`. Each KPI lists its inputs (symbols used in the dashboard's worked calculation), the source of every input and the formula. Synthetic sample values are for the default scope (YTD Jan-Oct 2026).

## Conventions

- `Σ` sums over every record in the selected scope (period × filters). Ratios are re-computed from summed numerators and denominators, never averaged.
- Flow measures sum over the period; snapshot measures use the state at the end of the period.
- Percentiles use the nearest-rank method: value at rank ⌈0.95 × n⌉ of the sorted observations.
- Currency is AED; token prices are AED per million tokens.
